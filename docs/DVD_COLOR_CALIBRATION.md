# DVD-R 43533：从纹理标定盘到自建色表

目标：一张标定盘用于拍摄、补拍、拟合和软件验证，再用一张新盘验证图片。程序不会自动刻录；物理写入仍通过 DIS 原有刻录页。

## 原作者工具核查

2026-11-14 检查 Neo-626/DiscColorStudio 公开 main（`ef44b13694e9873fc47ea9e0040ec5af502995ae`）、近五个发行版资产和相关公开 issue。README 明确说明：搜索盘生成工具、工程、ISO 和原始校准照片不包含在仓库或发行包中。公开的 CalibrationForm/CalibrationFiles 处理的是 DIS 盘面几何，不是照片颜色建表。

[作者的原理与搜索盘说明](https://github.com/Neo-626/DiscColorStudio/blob/ef44b13694e9873fc47ea9e0040ec5af502995ae/README.zh-CN.md#原理)；[v0.8.5 发行版](https://github.com/Neo-626/DiscColorStudio/releases/tag/v0.8.5)。

本实现沿用“已知字节纹理 + 相对轨道方位 → 实测线性 RGB → 非负混色配方”的思路。自建表采用公开 DCS v3 格式和凸组合拟合；不宣称复刻作者未公开的离线 v5 训练器。内置 95058 表仍保留原 v5 四组配方。

## 1. 生成并刻录标定盘

打开采用 43533 几何的 DVD 工程，进入「全彩 → DVD 实测色表 · 一张盘标定」，点击「生成标定布局」。设计页可以没有图片。

| 文件 | 用途 |
| --- | --- |
| `chart.json` | 完整几何、网格、纹理字节、混合比例、定位码；后续取样绑定其 SHA-256 |
| `layout.png` | 纹理编号示意，颜色不是实盘预测，不能当普通图片刻录 |
| `patch-key.csv` | 测试块编号、位置、半径、配方 |
| `capture-plan.csv` | 每 5° 一张、0–355° 的拍摄清单 |
| `拍摄说明.txt` | 可离线阅读的操作步骤 |

布局包含 1,154 个基础纹理格、128 个径向重复格和 48 个独立混色验证格。64 种代表纹理在内、中、外圈重复；重复和混合格不参与基础响应拟合。默认网格 2.1 mm、有效纹理格 1.8 mm。四个定位码带 T/R/B/L 人眼可读字母。

点击「导出标定 ISO」。输出直接指定逻辑扰码载荷纹理，使用原始 DVD 编码/几何采样，不通过旧 95058 表选色。混合格按真实螺旋圈号分配纹理，保留全局逻辑字节相位。完整镜像 **4,706,074,624 bytes**，计算全文件 SHA-256；同名发布沿用占用重试和完整镜像恢复机制。

在原有刻录页，用空白单层 43533 DVD-R、同一光驱支持的 4× 写入一次。记录实际光驱、固件和速度；“计划 4×”不代表已经以 4× 写入。标定模式使用独立 ISO 路径，返回图片模式恢复原图片输出路径。

## 2. 固定光路拍摄

1. 固定一盏白光单 LED 灯和手机/相机。先找到明显显色的位置，再记录光源和相机的距离、高度及方向，拍摄期间保持不动。
2. 锁定镜头、焦距、对焦、ISO、快门和白平衡；关闭 HDR、夜景、滤镜及自动增强。盘片保持平放，只绕盘心转动。
3. 优先 RAW/DNG。JPEG/PNG/TIFF 须统一为普通 sRGB 导出；不要把已经线性化的 TIFF 当 sRGB 照片输入。处理照片路径会标记为近似相对响应。
4. 每约 5° 拍一张清晰整盘原图，转满 360°，约 72 张。首尾额外拍同一摆位可检查漂移。纹理分布在不同方位，仅转 60° 不能测全同一个观看窗口。
5. 保留原文件，不经聊天软件压缩。过曝、模糊、遮挡、缺角度时补拍同一张盘，不需要因此重新刻录。

这是固定光路下的相机相对响应，不是标准 XYZ 色度计测量，不能保证跨光源、相机或刻录条件通用。

## 3. 导入、配准与取样

填写「刻录与拍摄记录」，点击「导入/追加照片并取样」。

- 自动识别 T=10、R=11、B=12、L=13 的 ArUco 码，使用至少三个码的角点拟合平面单应性。
- 第一张可用照片为参考姿态，其他照片通过相对单应性求实际转盘角度；文件名里的角度不会冒充实测值。
- 相对比例、盘心位移或透视变化过大时排除该帧，提示复查拍摄位置。
- 自动失败时选择照片，点「当前照片四点配准」，按 T/R/B/L 的身份依次点击码中心，不能按旋转后的屏幕上下左右猜顺序。
- 缩略图叠加中心取样区：绿色可用，红色跳过。应确认网格落在测试块中心，不能用四点拟合掩盖明显镜头畸变。

取样使用测试格中心约 44% 宽度，避开边界并排除明显过曝。RAW 固定采用首张 RAW 的白平衡、线性 sRGB/16 bit 输出，关闭自动亮度和逐帧白点拉伸；处理照片统一转线性 sRGB，但仍保留其近似性质。

原图不改写。会话目录保存 `session.json`、原图哈希、配准矩阵、姿态、取样记录和缩略图。可用「打开取样会话」恢复、追加照片或修正配准。

## 4. 质量检查与 LUT

默认寻找宽 60°、至少 90% 纹理具有连续实测支撑的窗口；可调整为 5–120°、50–100%。不能跨过超过 7.5° 的观测空缺，不用 95058 数值补缺测。

每个角度使用实测 RGB 三维凸包：色域内用四面体凸组合，色域外投影到最近凸包三角面。权重非负、总和为 1。1° LUT 节点是插值，不代表以 1° 拍摄。预览和 DVD 编码读取同一 LUT，保持每圈混色和全局字节相位。

重复格检查半径一致性，混合格独立检查线性混色。首版工程门限为两组各至少 24 个有效检查，中位归一化线性 RGB 误差 ≤0.12、P95 ≤0.35。这些不是已验证的物理色差标准，更不是 CIE ΔE。

失败时只保存 `quality.json`、`quality.txt`、`coverage.png`，不发布可应用色表。可补拍、重配准，或调整并重新固定光路后用同一张盘重拍；明显径向差异不应直接平均掩盖。

通过后生成完整目录：

- `profile.json`、`measured-lut.bin.gz`；
- `quality.json`、`quality.txt`、`coverage.png`；
- 不可变的 `measurements.json`、`chart.json` 证据快照。

后续追加照片不改动旧表证据，新表使用新目录。照片解码和角度节点根据 CPU 亲和性、可用内存自适应并行，避免嵌套启动 BLAS/OpenCV 线程。

## 5. 应用与新盘验证

点击「应用新色表到设计」，生成图片预览。其他相同几何 DVD 工程可通过「导入已有实测色表」选择 `profile.json`，须保留整个色表目录。

导入检查 LUT、质量报告、取样记录、纹理清单哈希和几何。图片计划再保存一份色表与证据；会话继续编辑不会改变旧计划。设计、参数或色表改变后旧预览/ISO 失效。

检查预测后，用一张新盘在相同光驱、速度和光路下验证人物、肤色、灰阶和渐变。软件检查通过仍标为等待新盘验证，没有自动声称物理颜色已校准。

合成照片测试夹具标记 `synthetic=true`，可用于离线预览和诊断片段，禁止导出或复用为实盘 ISO。

## 明确选择的实验建表

默认建表仍要求原有摆位、7.5° 最大观测间隔和独立混色检查。需要直接尝试稀疏或不稳定照片时，可对 `dvdcal-build` 请求明确设置 `experimental: true`，并指定 `maxResponseGapDeg`（7.5–60°，默认 30°）；观看窗口和最低覆盖率仍由原参数控制。实验模式只接纳有配准矩阵和真实取样的帧，不把缺测补成 95058 数据。

实验表保留原始摆位失败记录和独立检查误差，以 `experimental-unvalidated`、`experimental=true`、`standardValidationPassed=false` 标记。它不会伪装成 `software-checks-passed`。GUI 可通过「导入已有实测色表」应用，展示实验提示并载入质量报告；预览/参数编辑使用原生 DCS v3 管线。实验 ISO 导出仍使用现有显式选择，合成测试数据依旧禁止实盘输出。

本机 2026-11-14 的 22 张真实 RAW 试验采用独立的元数据增益准备会话：ISO/快门相对补偿及 DNG BaselineExposure 相对补偿，保留逐帧因子、原始取样值和原图哈希。此补偿是实验假设，没有做逐图直方图拉齐，也未通过物理辐射一致性验证。生成的 60° 窗口为 252–312°，最低插值纹理覆盖率约 85.1%；独立混色 P95 误差约 0.496，仍不满足原 0.35 门限，因此仅发布实验表。没有据此声称实际图片颜色还原成功。

## 环境与验证

DVD 图片预览/编码仍由隔离 C# 工作进程执行；新增的标定布局、照片和建表需要 Python（NumPy、SciPy、Pillow、OpenCV、rawpy）。运行 `tools/setup-fullcolor.ps1` 安装，在标定卡片运行环境中选择解释器。本机开发环境随本次更新配置。

Python：`python -m unittest discover -s src/DiscImageStudio.FullColor.Engine/tests -v`。

设置 `DIS_DVD_CAL_FIXTURE_ROOT` 为尚不存在的临时目录，可保留合成测试夹具。再设置 `DIS_TEST_FULLCOLOR_PYTHON`，运行 ArchitectureTests 的 `--test-dvd-calibration`：检查原生命令、会话恢复、v3/v5 快速与原始配方一致性、证据、串并行编码及合成表出口阻止，不调用刻录器。
